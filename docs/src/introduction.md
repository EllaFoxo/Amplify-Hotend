# Introduction

Amplify Hotend is an FDM 3D printer hotend, with an integrated load cell force sensor. Its primary usage is for Z probing and homing, in order to enable
perfect first layers, with no Z offset calibration required. Provided with the heatsink is a USB breakout board, which provides the necessary hardware for Kalico to read and process the sensor data.

## Core Features

- Never need to calibrate a Z offset ever again
- No thermal drift in enclosed printers
- Always reads the true zero point of your bed, no scanning the wrong surface
- Works on any surface (smooth/textured PEI, glass, metal, etc.)
