# Kalico Firmware

Kalico is a community maintained fork of Klipper Firmware.

For the best user experience and printer reliability, we recommend users of Amplify switch to Kalico.

## Getting Started

> Click [here for the Kalico Migration Guide](https://docs.kalico.gg/Migrating_from_Klipper.html) guide.

Kalico provides their own documentation for setting up for the first time. We recommend you follow their guides first, before continuing here. Generally speaking, the process which follows below is identical that of Klipper.
